# Hors périmètre

Ce dépôt contient des définitions de skills et les ressources nécessaires à leur usage.

Il ne contient pas :

- d’application autonome sans lien direct avec un skill ;
- de sortie générée pour une demande ponctuelle ;
- de dépendance installée, de fichier compilé ou de secret ;
- d’intégration qui exécute une action externe sans contrôle explicite.

Documenter tout changement de périmètre dans `CHANGELOG.md`.
