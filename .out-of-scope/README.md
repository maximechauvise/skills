# Hors du périmètre

Ce que **ce repo ne fera pas**. Un skill qui tombe dans une de ces zones n'y a pas sa place — ou exige d'abord de repousser cette borne, avec un ADR.

- **Visuels, assets, design** : création d'images, de chartes graphiques, de maquettes. Les skills produisent du texte, des structures et des décisions — jamais de pixels.
- **Automatisation de publication** : envoyer du contenu à la volée (CMS, newsletters, social) sans validation humaine. Un skill peut *préparer* un envoi ; le déclenchement d'une publication reste un humain.
- **Vente / closing** : les skills aident la préparation de vente (positionnement, messages, ICP), pas l'exécution d'un call ni la négociation.
- **Data science** : analyser des data en profondeur relève d'un pipeline dédié. Un skill CRO peut lire un tableau et proposer des hypothèses ; il ne remplace pas une infra analytics.

> Toute évolution de ces bornes passe par un changset qui documente la décision.
